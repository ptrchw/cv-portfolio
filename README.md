# Peter Chow — CV & portfolio

Static personal site: CV, career journey and case studies.

- `index.html` — main CV/portfolio page
- `*-case-study.html` — case studies (EMA, capability building, NumLah, SafeGuardian)
- `numlah-*.html` — NumLah prototype and style guides
- `Peter-Chow-CV.pdf` — downloadable CV
- `brochure/` — supporting images

No build step: the folder is served as-is (GitHub Pages or Cloudflare Pages, output directory = repository root).
